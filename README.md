# Smart-Parking-Slot-Monitoring-and-Vehicle-Detection-System-using-CAN-Protocol
An ARM7 LPC2129-based Smart Parking System developed using Embedded C and CAN protocol. Monitors parking slot availability, detects vehicle entry and exit using IR sensors, displays real-time status using a 20×4 LCD, integrates DS1307 RTC via I2C, and controls the parking gate using a servo motor.
